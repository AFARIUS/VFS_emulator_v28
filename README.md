# VFS Emulator (Вариант 28)

Эмулятор командной оболочки UNIX-подобной ОС. Этап 1: REPL.

## Описание

Приложение реализует консольный интерфейс (CLI) с приглашением, содержащим имя VFS.
Поддерживаются команды-заглушки `ls`, `cd`, а также команда `exit`.
Неизвестные команды обрабатываются с выводом сообщения об ошибке.

## Функции и настройки

- Имя VFS задается в `Main.java` (по умолчанию `VFS28`).
- Парсер разделяет ввод на команду и аргументы по пробелам.
- Команды `ls` и `cd` выводят свое имя и переданные аргументы.
- Команда `exit` завершает работу.
